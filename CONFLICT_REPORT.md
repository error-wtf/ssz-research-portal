4. **Blend implementation drift:** `segmented-calculation-suite/segcalc/methods/xi.py` uses a quintic zero-slope smoothstep to mix two non-flat branch functions. That is not the endpoint-derivative-matched P0 construction and does not, by itself, make the global field C².
5. **Strong-field exponent:** reversed/global saturation variants are legacy or local-only, not the operational global branch.
6. **Test totals:** counts from functions, parametrisations, logs and audits are reported separately.
7. **Strong-field observable numbers:** values require explicit metric, branch and derivation provenance.
