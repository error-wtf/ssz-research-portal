# Contributing

Contributions must preserve the public-only scope, the P0 source hierarchy and the distinction between derivation, implementation, internal test, data compatibility, fit, prediction and empirical confirmation.

Every scientific change should:

1. add or update a stable Claim-ID;
2. identify formula, domain, observer and coordinate conventions;
3. link source bytes, repository path and commit;
4. provide a reproducible test or mark it explicitly open;
5. state what the result does not prove;
6. state a falsification or rejection condition;
7. pass all local validators listed in `REPRODUCIBILITY.md`.

Do not include credentials, absolute local paths, mixed private research material, invented data, hidden parameters or claims of complete central regularity.
