# Formula Catalogue

- `data/formulas.json`: 16 human-curated central equations with meaning, variables, units, domain, limits, example, code mapping, tests, source and caution.
- `data/formula-candidates.json`: 4,000 deduplicated automatically extracted equation candidates.

Candidate extraction includes existing Markdown, text and TeX sources. Candidates are never promoted to canonical status without context review. The website renders mathematics as accessible HTML/Unicode and uses no TeX build.
