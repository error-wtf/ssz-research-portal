# Repository Catalogue

The publishable local physics inventory contains **34** repositories after private-source exclusion. `data/repositories.json` records public URL where known, neutral local reference, role tags, branch, commit, commit date, latest local tag, hosting status, dirty/clean state, file count and test-related file count.

The source list in `rag/repositories.md` also contains non-physics repositories. The portal restricts the interactive research catalogue to repositories found under the physics corpus and does not alter them.
