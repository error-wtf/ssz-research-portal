How to read this atlas

Source coverage

README prose provides an orientation only. Key documents and result files expose the deeper sources that must be checked before quoting a result.

Cross-version caution

Repositories preserve multiple historical SSZ variants. The P0 hierarchy, formula locks and exact commit remain mandatory when results conflict.

Evidence boundary

A large repository or test count measures engineering activity. Scientific weight depends on derivation, assumptions, data provenance, uncertainty and independent comparison.
