Codec for All Segmented Units

A compatibility-first media architecture for representing state, change and timing as explicit segmented units. CASU is an independent engineering branch of this portal, not a derivation from SSZ physics.

CASU
Identity and boundary

One name, two explicitly separated projects

Format / codec

CASU

Codec for All Segmented Units. The proposed container and codec model for audio, video and future state-oriented media streams. Its file extension is .casu.

CASU may store decoded media units, change descriptions, timing, provenance and compatibility metadata. It must preserve source timing and provide a lossless legacy fallback whenever a segment cannot be represented safely.

Application

MPCASU

MPCASU is the planned reference media player for CASU and established formats such as MP4, MP3, MKV and FLAC. A player implementation is software evidence about compatibility and performance; it is not evidence for a gravitational model.

Scientific separation: SSZ physics and CASU share a conceptual interest in local, segmented state, but SSZ physics ≠ CASU codec. No metric equation, redshift result or RH candidate is used as a codec proof. CASU performance must stand on its own reproducible media benchmarks.
Core abstraction

State + Segment + Change + Timing

CASU treats a media stream as a sequence of explicitly timed units. A unit can carry a complete state, a bounded change from a known state, or a conservative fallback frame/audio block.

\[\boxed{\text{State}+\text{Segment}+\text{Change}+\text{Timing}}\]

State

The reference pixels, samples or decoded object state required to interpret a unit.

Segment

A spatial, temporal or semantic region with explicit bounds and provenance.

Change

The validated delta, event or replacement payload relative to a declared base state.

Timing

Presentation timestamps, duration, clock domain and synchronization metadata remain canonical.

Compatibility-first pipeline

Legacy media remains a first-class input

CASU does not require users to abandon established media. A reference implementation can decode a legacy stream, derive optional segments, and fall back to the original decoded path whenever a transformation is uncertain.

standard decoder ──► canonical timestamps and decoded reference state

Preserve

Source timestamps, A/V synchronization, colour/HDR metadata, sample rate, channel layout and seek semantics.

Conserve

Where validated, avoid redundant decoding, compositing, memory copies or display updates for unchanged regions.

Fallback

If a delta is incomplete, stale, out of order or outside the confidence policy, reconstruct or present the full reference unit.

Protocol invariants

What a conforming implementation must not silently change

  • Never invent presentation time or silently time-stretch the source.
  • Never change pitch, colour, HDR transfer, sample format or channel meaning without an explicit transform record.
  • Every change unit names its base state, segment scope, timestamp and integrity metadata.
  • Seeking invalidates dependent caches unless their state lineage is verified.
  • Out-of-order or corrupted segments trigger conservative recovery, not silent continuity.
  • Audio/video clocks remain independently inspectable and synchronizable.
Evidence and limits

Prototype status, not a performance claim

The CASU/MPCASU implementation is currently maintained as a local prototype with legacy media fixtures and compatibility tests. This public portal does not claim a completed codec standard, independent benchmark victory, energy saving or perceptual superiority.

Those claims require fixed input files, decoder settings, hardware/software versions, CPU/GPU time, memory traffic, display-update counts, bitrate, latency, A/V sync and objective quality metrics. A CASU file that decodes correctly is evidence of compatibility—not automatically evidence of efficiency.

Open

Format specification

Container versioning, checksums, indexes, segment dependencies and recovery rules need independent review.

Open

Player implementation

MPCASU must be tested against real MP4/MP3/MKV inputs, seeking, interruptions, malformed units and device clock drift.

Open

Benchmarks

Any reduction in work or memory movement must be demonstrated against a fixed legacy baseline with reproducible measurements.

CASU is an application branch. It is conceptually inspired by segmented state reasoning but is not a result of SSZ physics.
