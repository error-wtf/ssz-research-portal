External review path

Audit a claim without trusting the portal

  1. Resolve the Claim-ID

    Read the precise statement, domain, observer scope and explicitly excluded implications.

  2. Verify source bytes and commit

    Compare the SHA-256 hash, repository path and commit with the cited public source.

  3. Reproduce the code path

    Run the recorded command with the declared inputs and inspect numerical tolerances.

  4. Challenge the evidence class

    Decide whether the result is an identity, numerical check, compatibility result, fit or genuinely discriminating observation.

  5. Apply the falsification condition

    Record negative results and dependencies instead of averaging them into a green aggregate.
