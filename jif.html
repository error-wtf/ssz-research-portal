General

Phase count

dJ=dΦ/(2π)

One complete phase revolution ΔΦ=2π is one JIF. J is dimensionless.

Massive/bound

Proper oscillator

dJ=f₀dτ

A bound system of proper frequency f₀ counts cycles along its timelike worldline.

Photon

Path phase

ΔJγ=(1/2π)∫γkμdxμ

Because dτγ=0, photon JIF is a null-path phase, never f dτ.

SSZ coupling

From coordinate time to phase count

dτ=D(r)dt   ⇒   dJ=f₀D(r)dt   ⇒   dJ/dt=f₀D(r)

Dimensions

f₀ has unit s⁻¹, dτ has unit s, and dJ is a pure cycle count. D and Ξ are dimensionless. A unit mismatch is therefore an immediate implementation failure.

Quantum phase

For a stationary bound state, dΦ=(E/ℏ)dτ. With E=hf₀ and h=2πℏ, this reduces directly to dJ=f₀dτ.

Why the force-based definition was rejected

An earlier proposal used Jμ=KμΔτ and a ratio |J|/|K|. That only collapses to Δτ for a constant four-force of fixed direction and magnitude, and it fails as a general photon definition. The canonical JIF definition is phase-based.

Examples and experimental limits

Optical clocks

Compare accumulated phase between clocks at different potentials. Required: common transfer link, systematic-shift model, covariance, and a predeclared SSZ-vs-reference prediction.

Interferometers

Compare path phases. Required: optical path geometry, mirror motion, laser noise, gravitational potential, and an explicit one-way/two-way convention.

Strong-field timing

Potentially large D differences are attractive, but real sources add Doppler, plasma, rotation, emission-region, and model-degeneracy uncertainties.

Current limit: JIF is an operationally clean phase bookkeeping framework. A distinct experimental advantage over conventional relativistic phase modelling must still be demonstrated through a preregistered measurement protocol.
