Core phase model

The public code uses a numerically stable difference of the SSZ clock factor for nearby radii.

Stable differential

\[\Delta D=\frac{2r_s(r_1-r_2)}{(2r_1+r_s)(2r_2+r_s)}\]

This avoids subtracting two nearly equal floating-point values. The phase accumulated in a gate is then \(\Delta\Phi=\omega\Delta D t\).

Entanglement observables

\[F=\cos^2\!\left(\frac{\Delta\Phi}{2}\right),\qquad S=2\sqrt2\cos(\Delta\Phi)\]

The repository treats \(T_{\mathrm{SSZ}}=\pi/(\omega|\Delta D|)\) as a deterministic geometric phase time, not as a decoherence time.

Evidence boundary: these are model calculations and software tests. They are not an experimental confirmation that SSZ governs qubit hardware.

Conceptual bridge

Surface-code connection

A coherent phase bias could, in principle, be injected as a \(Z\)-type term in a surface-code cycle:

\[H_i=\frac{\hbar\omega_i}{2}D(\mathbf x_i)\sigma_z\]

The current repository does not reproduce Google's Willow device, syndrome cycles, decoder graph or logical-error data. A meaningful next experiment would compare \(p_L(d=3),p_L(d=5),p_L(d=7)\) with no bias, an SSZ bias and active compensation.
