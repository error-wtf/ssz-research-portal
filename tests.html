Evidence ladder

What a PASS does and does not mean

1. Unit

A function returns expected values for declared inputs.

2. Integration

Components agree on interfaces, units, and data flow.

3. Reference

An implementation reproduces an analytic limit or external reference.

4. Empirical

Independent data prefer the model after uncertainties and alternatives are included.

A software test is evidence about an implementation under its assertions; it is not an automatic empirical confirmation of nature.
